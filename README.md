# Tarun A — UI/UX Designer Portfolio

A minimalist, editorial, 3D interactive personal portfolio website for **Tarun A**, UI/UX Designer based in Chennai, India.

> *"Most portfolios try to impress. This one tries to communicate."*

---

## 🚀 Live Overview & Core Features

- **Editorial & Asymmetric Design System**: Clean off-white background (`#F8F7F4`), charcoal typography, and electric blue accents (`#0047FF`).
- **Interactive 3D Hero Experience**: Three.js & React Three Fiber floating design panels and geometric elements responding to cursor movement with smooth physics.
- **12 Real Case Studies & Projects**: Extracted and preserved directly from [Tarun's Behance Profile](https://www.behance.net/tarun_a) with all original project images, tools, tags, metrics, and case study breakdowns.
- **Dedicated Project Detail Routes (`/work/[slug]`)**: Static pre-rendering (SSG) for all 12 projects with full-bleed visual galleries and a responsive Lightbox.
- **Custom Desktop Cursor**: Interactive state-aware cursor ("VIEW", "EXPLORE", "ZOOM", "↗", and magnetic pointer), gracefully disabled on touch and mobile.
- **Mobile First & Highly Accessible**: Full responsive support from 320px to 4K displays, WCAG contrast compliance, and full `prefers-reduced-motion` fallbacks.
- **SEO & Structured Data**: Complete Open Graph, Twitter/X cards, and JSON-LD Person schema.

---

## 🛠 Tech Stack

- **Framework**: [Next.js 14](https://nextjs.org/) (App Router, Static Site Generation)
- **Language**: [TypeScript](https://www.typescriptlang.org/)
- **Styling**: [Tailwind CSS](https://tailwindcss.com/)
- **3D Graphics**: [Three.js](https://threejs.org/) + [@react-three/fiber](https://docs.pmnd.rs/react-three-fiber)
- **Animations**: [Framer Motion](https://www.framer.com/motion/)
- **Icons**: [Lucide React](https://lucide.dev/)

## 💻 Getting Started Locally

```bash
# Clone the repository
git clone https://github.com/pjtssv2009-cmd/tarunportfolio.git

# Install dependencies
npm install

# Start local development server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to view the portfolio.
